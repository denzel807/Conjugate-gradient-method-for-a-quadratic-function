# Conjugate Gradient Visualizer

Графическое приложение на Python для визуализации работы метода сопряжённых градиентов при поиске минимума квадратичной функции двух переменных.

Программа позволяет задавать параметры функции, начальную точку, требуемую точность и максимальное количество итераций, после чего выполняет метод сопряжённых градиентов и отображает процесс поиска минимума на интерактивном 3D-графике.

## Исследуемая функция

Программа работает с квадратичной функцией вида:

`f(x, y) = A·x² + B·y² + C·x·y + D·x + E·y + F`

Пользователь может самостоятельно изменять все коэффициенты функции.

Для корректной работы с выпуклой функцией программа проверяет условия:

- `A > 0`;
- `B > 0`;
- `4AB - C² > 0`.

## Основные возможности

- ввод коэффициентов квадратичной функции;
- выбор начальной точки `(x₀, y₀)`;
- настройка точности вычислений;
- настройка максимального количества итераций;
- реализация метода сопряжённых градиентов;
- вычисление градиента функции;
- построение матрицы Гессе;
- аналитическое вычисление точной точки минимума;
- сравнение результата метода с точным решением;
- построение трехмерной поверхности функции;
- отображение начальной точки и точки минимума;
- анимация движения по траектории метода;
- плавная интерполяция пути для визуализации;
- отображение текущих координат и значения функции;
- отображение нормы градиента;
- вывод количества выполненных итераций;
- отдельное окно с ходом работы алгоритма;
- проверка корректности введенных данных;
- сброс параметров к исходным значениям.

## Метод сопряжённых градиентов

В программе реализован классический алгоритм сопряжённых градиентов.

На первой итерации направление движения выбирается противоположно градиенту:

`d₀ = -g₀`

После этого на каждом шаге вычисляется оптимальный коэффициент:

`αₖ = -(gₖᵀdₖ) / (dₖᵀHdₖ)`

и новая точка:

`xₖ₊₁ = xₖ + αₖdₖ`

Новое сопряжённое направление рассчитывается с использованием коэффициента:

`βₖ = (gₖ₊₁ᵀgₖ₊₁) / (gₖᵀgₖ)`

После чего:

`dₖ₊₁ = -gₖ₊₁ + βₖdₖ`

Вычисления продолжаются до достижения требуемой точности или максимального количества итераций.

## 3D-визуализация

Matplotlib используется для построения трехмерной поверхности квадратичной функции.

На графике отображаются:

- поверхность функции;
- линии уровня;
- начальная точка;
- точный минимум функции;
- текущая точка алгоритма;
- траектория поиска минимума.

Траектория дополнительно интерполируется, благодаря чему движение точки по поверхности отображается в виде плавной анимации.

## Интерфейс

Графический интерфейс создан с использованием `Tkinter`.

Главное окно содержит:

- панель параметров функции;
- параметры алгоритма;
- кнопки запуска и сброса;
- трехмерный график;
- окно с подробным ходом вычислений;
- справочную информацию о методе.

Также в программе предусмотрены информационные разделы:

- история метода;
- описание алгоритма;
- примеры применения.

## Запуск

Установите необходимые библиотеки:

```bash
pip install numpy matplotlib
```

После этого запустите программу:

```bash
python rgr_3_Musiyan.py
```

`Tkinter` обычно входит в стандартную поставку Python, но в некоторых системах его может потребоваться установить отдельно.
