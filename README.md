# Conjugate-gradient-method-for-a-quadratic-function
  Изначально разработан для решения систем линейных уравнений с симметричной положительно определённой матрицей.  Позже метод был адаптирован для задач безусловной минимизации нелинейных функций.  
  Особенность: для квадратичной функции метод сходится максимум за n шагов, где n — размерность пространства (в нашем случае за 2 шага).
